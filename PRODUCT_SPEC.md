# Прототип личного тренировочного дневника

## Главная задача

За несколько секунд записать максимальный рабочий вес и число повторений для каждого выполненного упражнения.

## Зафиксированные правила

- Единица веса — килограммы, дробные значения разрешены.
- В одной тренировке хранится один результат на упражнение: максимальный вес и повторения.
- Лучший результат — наибольший вес за всю историю; при одинаковом весе выигрывает большее число повторений.
- Прошлый результат — последняя завершённая тренировка, в которой присутствовало это упражнение.
- Дата лучшего результата на рабочем экране не показывается.
- Упражнение без заполненного результата не попадает в завершённую тренировку.
- Для завершения тренировки достаточно сохранить результат хотя бы одного упражнения.
- У пользователя может быть только одна активная тренировка.
- После закрытия Mini App активная тренировка восстанавливается по `started_at`.
- Таймер не требует фонового процесса: длительность вычисляется как разница между текущим временем и `started_at`.
- История и программа каждого Telegram-пользователя изолированы.

## Входит в первый прототип

- главный экран и запуск тренировки;
- выбор любой тренировки непосредственно на главном экране;
- таймер общей длительности;
- несколько программ с выбором нужной перед тренировкой;
- создание новой программы;
- удаление любой программы, включая последнюю;
- добавление и удаление упражнений в программе;
- создание собственного упражнения с названием и категорией;
- удаление ошибочно созданного упражнения, если по нему ещё нет сохранённой истории;
- изменение порядка упражнений;

Каждому новому пользователю доступны три заполненные базовые тренировки. Базовый каталог содержит 14 согласованных упражнений. В каталоге они сгруппированы в порядке: плечи, бицепс, трицепс, грудь, спина, предплечья, ноги. Внутри пользовательской программы порядок остаётся ручным.
- быстрый ввод веса и повторений;
- лучший и предыдущий результаты;
- отметка нового рекорда;
- завершение и отмена тренировки;
- история с раскрытием результатов;
- восстановление состояния после закрытия страницы;
- мобильная адаптация и клавиатурная доступность;
- PostgreSQL-схема для Neon;
- проверка подписи Telegram Mini App;
- закрытый список разрешённых Telegram ID;
- webhook `/start` с кнопкой запуска Mini App.

## Не входит сейчас

- подходы, разминка, RPE/RIR, кардио и упражнения с собственным весом;
- фотографии упражнений;
- напоминания;
- социальные функции и общая статистика пользователей;
- сложные графики, оценочный 1ПМ и тренировочный объём;
- одновременная работа без сети на нескольких устройствах;
- переименование программы;
